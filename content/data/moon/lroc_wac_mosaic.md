### Overview
This analysis-ready data (ARD) release provides LROC Wide Angle Camera (WAC) morphology basemaps of the Moon as Cloud Optimized GeoTIFFs. The LROC {{< cite "Robinson:2010" >}} Wide Angle Camera aboard the Lunar Reconnaissance Orbiter (LRO) maps the whole Moon in one month; the global mosaic is comprised of over 15,000 images acquired between November 2009 and February 2011 at 643 nm. To even out the solar incidence angle variations (generally between 55 and 75 degrees at the equator), the equatorial mosaic is built from data collected over three periods (1/20/2010 to 1/28/2010, 5/30/2010 to 6/6/2010, and 7/24/2010 to 7/31/2010). The south polar mosaic images were acquired 8/10/10 to 9/19/10 and the north polar images 4/22/10 to 5/19/10; some gores were filled with data taken at other times.

The collection contains three tiles: a global equirectangular mosaic at 303 pixels/degree (v3, June 2013), and north and south polar cap mosaics at 100 m/pixel (v2) covering the 60 to 90 degree latitude regions. The non-polar images were map projected onto the GLD100 WAC-derived 100 m/pixel grid, while the polar images were map projected onto the Lunar Orbiter Laser Altimeter (LOLA) shape model (80 to 90 degrees N/S) and the GLD100 (60 to 80 degrees N/S). An improved camera pointing and the LOLA crossover-corrected ephemeris provide accurate positioning of each WAC image.

**These basemaps are intended for visualization and context only. They are 8-bit qualitative products and are NOT intended for quantitative analysis or hard science use.** See [General Usability](#general-usability).

### Processing
The mosaics were generated by the LROC team at Arizona State University following the methods described in {{< cite "Speyerer:2011" >}} and {{< cite "Wagner:2015" >}}. The steps below describe how the existing mosaic products were prepared for this ARD release on the USGS Hovenweep supercomputer; they are provided so that the release can be regenerated from the source files.

#### Input Products
The input products are the LROC team's published mosaics: the global WAC morphology mosaic at 303 pixels/degree (version 3) and the north and south polar WAC mosaics at 100 m/pixel (version 2), each a single-band 8-bit (Byte) grayscale GeoTIFF.

#### Coordinate Reference System
The three tiles carry three different IAU 2015 projections: the global mosaic is equirectangular with a central meridian of 180 degrees (**IAU_2015:30115**), the north polar cap is north polar stereographic (**IAU_2015:30130**), and the south polar cap is south polar stereographic (**IAU_2015:30135**), all on the Moon (2015) sphere of radius 1,737,400 meters. The STAC item's `proj:code` is taken from each tile's own coordinate system.

#### Raster Preparation
Each tile was written as a Cloud Optimized GeoTIFF (COG) preserving the 8-bit (Byte) data type, with LZW compression and BigTIFF enabled, and an overview pyramid (overview level 2, nearest-neighbor resampling) so that the large global mosaic (244,098 by 122,049 pixels, ~18 GB) can be served efficiently by web map and titiler services. A small JPEG browse thumbnail was generated for each tile; for the global mosaic the thumbnail is a 20-degree-by-20-degree crop centered on (0, 0) rather than a downscaled full-width sliver.

#### Footprints
The geographic footprint (extent) of each STAC item tracks the actual data: the raster's georeferenced boundary, densified to follow pixel edges, reprojected to the IAU 2015 code 30100 (geodetic latitude/longitude), and simplified (0.1 degree tolerance) to remove the pixel-edge vertices.

#### Metadata and Quality Assurance
Spatio-Temporal Asset Catalog (STAC) metadata were generated for each tile using the automated metadata generation (amg) library, combining the raster metadata of the COG, the footprint geometry, and release-level overrides (including the data citation). Because a mosaic has no single sensical acquisition time, the item `datetime` is the release time. Each item was validated before release: the file count per tile, the coordinate reference system of the COG (which must match the item's `proj:code`), the presence of the COG overview pyramid, and the STAC item (projection code, collection, asset count, and that each asset link resolves).

### Available Assets
Each item provides the following assets:
- **basemap** — the 8-bit morphology mosaic as a Cloud Optimized GeoTIFF (LZW compression, with overviews). Pixel values are 8-bit grayscale (0-255); for the polar tiles, 0 is the nodata value outside the cap.
- **thumbnail** — a JPEG browse image of the tile.
- **provenance** — a text file recording the exact commands used to prepare the product.

### Accuracy, Errors, and Issues
The mosaics are morphology products: their value is in the accurate *positioning* of surface features, not in radiometric fidelity. The image positioning relies on the LOLA crossover-corrected ephemeris and improved camera pointing (see {{< cite "Speyerer:2011" >}}). <!-- PLACEHOLDER: if the LROC team publishes a geolocation accuracy statement for the v3 mosaics, record it here with the citation; do not estimate. -->

There are no companion error products. Known issues:
- **Brightness discontinuity at +/-60 degrees latitude.** The polar mosaics were acquired at a different season than the equatorial mosaic, and the lunar photometric function is not perfectly known, so a brightness difference can be seen where the polar mosaics meet the equatorial mosaic. This was greatly reduced in version 3 (June 2013) but not eliminated.
- **8-bit data type.** The mosaics are 8-bit (qualitative) products; radiometric information from the original WAC observations is not preserved.
- **Polar tile nodata.** The north and south polar tiles carry nodata value 0 in the corners outside the circular cap (below 60 degrees latitude).

### General Usability
**These basemaps are for visualization and context only. They are NOT for hard science use.** Specifically:
- Do not use these mosaics for quantitative radiometric analysis, photometric modeling, or any measurement that depends on pixel values. The 8-bit blending across seams produces an aesthetically consistent product, not a radiometrically consistent one. For quantitative WAC analysis, use the individual WAC observations.
- Do not use these mosaics for geodetic measurements beyond the positioning described above. They are a basemap: use them to orient, locate, and display other data.
- The three tiles use three different projections (IAU_2015:30115 equirectangular for the global, IAU_2015:30130/30135 polar stereographic for the caps). Reproject to a common system before combining tiles in analysis; for display, the web map handles this.
- The global mosaic spans the full sphere in equirectangular projection with a central meridian of 180 degrees; longitudes run -180 to 180 in the STAC metadata.
